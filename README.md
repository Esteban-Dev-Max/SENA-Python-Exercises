📂 Proyecto: Agenda de Notas
Esta aplicación permite gestionar tareas pendientes y ver el historial mediante el manejo de archivos de texto y módulos.

🛠️ Requisitos
Python 3.x instalado.

🚀 Cómo ejecutarlo
Descarga o clona este repositorio.

Abre la terminal en la carpeta del proyecto.

Ejecuta el archivo principal:

Bash
python main.py
📄 Contenido del proyecto
main.py: Interfaz de menú y control principal.

gestion_notas.py: Funciones para crear y leer las notas.

historial_notas.txt: Archivo donde se guardan los datos.
